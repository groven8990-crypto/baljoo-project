🔍 자동 검토 — 샵마인 원본 vs 발주서 결과 수량 대조
각 발주서를 미리 만들어보고 샵마인 원본의 선택사항(Q)·노출상품명(쿠팡)에 있는 옵션(kg, P 규격)이 발주서에 제대로 반영됐는지 자동으로 점검해요.
⚠️ 가 뜨면 다운로드 전에 의심 행 표를 펼쳐서 확인. 동일(깐마늘)은 옵션을 1kg으로 고정 + 수량에 kg 곱해주는 방식이라 그게 정확한지도 같이 봅니다.

  • 📊 보고서 생성 클릭 → 자사(로또상회·자꾸가게)·디네트 매출이 한 장에 정리
3단계 · 저장 / 공유
  • 💾 이력에 저장 클릭 → 그날 데이터가 주간 매출에 합산되도록 누적됨
  • 🖼 이미지(PNG) 저장 클릭 → 보고서를 그대로 PNG로 다운로드
  • 둘은 별개 — 이미지만 저장해도 누적엔 안 들어가요. 주간 합산이 필요하면 꼭 💾 이력에 저장도 눌러주세요
수정하려면
  • 📆 주간 매출 탭 → 📋 누적 이력 보기 → 해당 날짜의 수정 버튼
  • 이 탭으로 돌아와서 그 날짜로 다시 생성 + 💾 저장 → 자동 덮어쓰기
💡 상품명이 잘려서 이상하게 나오면 (예: "휴대용 터빈 손") 위 🏷️ 상품명 별칭 관리에서 직접 등록하세요.
💡 다른 컴퓨터로 옮길 때는 코드 관리 탭 → 📤 전체 데이터 내보내기 / 📥 가져오기 활용.
📆 주간 매출 보고용
매출 보고용에서 매일 📊 보고서 생성을 누르면 그날 데이터가 자동으로 누적돼요. 여기서 주차를 골라 합산 보고서를 만들 수 있어요.

📖 사용 방법
1단계 · 일일 누적
  • 매일 📈 매출 보고용 탭에서 보고서 생성 후 💾 이력에 저장 누르면 그날 데이터가 누적됨
  • 저장 안 하고 이미지만 받으면 주간엔 안 들어가요
  • 월요일에 시작 안 했어도 OK — 그 주에 저장한 날만 합산
2단계 · 주간 합산
  • 아무 날짜만 입력 → 그 날이 속한 월~일 주간 자동 계산
  • 📊 주간 보고서 생성 클릭 → 일자별 요약 + 브랜드별/디네트 누적
3단계 · 저장
  • 🖼 이미지(PNG) 저장 → 주간 보고서를 PNG로 다운로드
누적 관리
  • 📋 누적 이력 보기 → 저장된 일일 데이터 확인
  • 수정 버튼: 매출 보고용 탭으로 점프 → 그 날짜로 다시 생성 + 저장 → 덮어쓰기
  • 삭제 버튼: 그 날짜 이력만 제거
💡 데이터가 안 보이면 → 매출 보고용 탭에서 그 날의 보고서를 먼저 생성하셔야 누적됩니다.
