# 샵마인 신규 주문 → 발주 알리미 폰 알림 (Windows)

샵마인을 켜 둔 PC에서 이 스크립트를 실행해 두면 다음과 같이 동작합니다.
1. 정해진 간격(기본 10분)마다 샵마인의 **[수집하기] → [엑셀파일생성]**을 자동으로 누릅니다.
2. 저장 폴더에 새 샵마인 엑셀이 생기면 서버로 보냅니다.
3. 서버는 **처음 보는 주문만** 골라 담당자 폰으로 알림을 보냅니다.

- 주문 하나는 한 번만 알립니다. 같은 파일을 다시 올려도 같은 주문이면 알림이 다시 가지 않습니다.
- 파일 자체는 서버에 저장하지 않습니다. 주문 정보만 이름을 가려서(김**) 저장하고, 주소는 시·군·구까지만 저장합니다.
- 처음 연결할 때는 이미 쌓여 있던 발송대기 주문을 알림 없이 저장만 합니다.
- PC가 꺼져 있으면 알림이 오지 않습니다. 다시 켜면 그 사이에 들어온 주문을 모아서 알립니다(24시간 이내 주문).

## 설치 (최초 1회)

1. [python.org](https://www.python.org/downloads/)에서 파이썬을 설치합니다. 설치 화면에서 **"Add Python to PATH"를 꼭 체크**하세요.
2. 명령 프롬프트(cmd)를 열고 아래를 실행합니다.
   ```
   pip install pyautogui pywin32
   ```
3. 이 폴더(`tools/shopmine-order-alert`)를 PC에 받습니다.
4. **`1_설정.bat`**을 더블클릭하고, 질문에 차례로 답합니다.
   - 연동 키: 발주 자동화의 📱 모바일 앱 연동에 넣은 키와 같은 키
   - 샵마인 엑셀이 저장되는 폴더
   - 버튼 위치 기록: 샵마인 화면에서 **[엑셀파일생성] 버튼 위에 마우스를 올리고 키보드 Enter**를 누릅니다. 저장 창의 [저장]이나 [확인] 버튼도 이어서 같은 방법으로 기록합니다. 다 기록했으면 `q`를 입력합니다.

## 사용

- **`2_실행.bat`**을 더블클릭합니다. 창은 켜 둔 채로 두면 됩니다.
- 시험 삼아 올려 보기: cmd에서 `python shopmine_alert.py --test`를 실행하면 저장 폴더의 가장 최근 엑셀 1개만 올립니다.
- 자동 클릭 없이 쓰기: 설정 4번에서 `n`을 고르면, 사람이 샵마인에서 엑셀을 저장할 때만 알림이 갑니다.

## 주의

- 자동 클릭이 도는 몇 초 동안은 마우스와 키보드를 건드리지 마세요.
- 긴급 중단: 마우스를 화면 **왼쪽 위 모서리**로 확 이동합니다. 종료는 창에서 `Ctrl+C`입니다.
- 샵마인 창 위치나 크기가 바뀌면 버튼 위치가 달라지므로 `1_설정.bat`을 다시 실행하세요.
- 자동 클릭은 07시~23시에만 돕니다. `config.json`의 `"hours"`에서 바꿀 수 있습니다.
- `config.json`에는 연동 키가 들어 있으니 다른 사람에게 공유하지 마세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "창을 못 찾았습니다" | 샵마인을 켠 뒤, 설정 3번의 창 제목 글자를 실제 창 제목에 맞게 수정 |
| "연동 키가 맞지 않습니다" | `1_설정.bat`에서 연동 키를 다시 입력 |
| "샵마인 발송대기 양식이 아닙니다" | 저장 폴더에 다른 엑셀이 있는 경우입니다. 무시해도 되고, 다시 올리지 않습니다 |
| 알림이 안 옴 | 폰 앱 → 톱니바퀴 → **신규 주문 알림 켜기**를 했는지 확인 (아이폰은 홈 화면 아이콘으로 연 상태에서) |
