# 발주서 카카오톡 자동 전송 (Windows)

발주 앱에서 발주서를 다운로드하면, 이 스크립트가 다운로드 폴더를 감시하다가
발주처별로 매핑된 **카톡 채팅방에 파일을 자동 첨부 전송**합니다.

## 설치 (최초 1회)

1. [python.org](https://www.python.org/downloads/)에서 파이썬 설치
   (설치 시 **"Add Python to PATH"** 체크 필수!)
2. 명령 프롬프트(cmd) 열고:
   ```
   pip install pyautogui pyperclip pywin32
   ```
3. 이 폴더(`tools/kakao-auto-send`)를 컴퓨터에 다운로드
4. `rooms.json` 을 메모장으로 열어 발주처별 카톡 채팅방 이름 등록:
   ```json
   {
     "일비": "일비 발주방",
     "최고집": "최고집 사장님",
     "사무실": "사무실 깐마늘"
   }
   ```
   - 왼쪽 = 발주처 이름 (파일명에 들어가는 그대로)
   - 오른쪽 = **PC 카톡에 표시되는 채팅방 이름과 정확히 동일하게**

## 사용법

1. PC 카카오톡 로그인해두기
2. cmd에서 실행:
   ```
   python kakao_sender.py
   ```
3. 발주 앱에서 발주서 다운로드 → 몇 초 안에 자동으로 해당 채팅방에 파일 전송됨

### 파일 하나만 보내기
```
python kakao_sender.py --once "C:\Users\me\Downloads\260710-일비-발주서_그로븐.xlsx"
```

## 주의사항

- **전송 중에는 마우스/키보드를 만지지 마세요** — 화면을 직접 조작하는 방식이에요
- 긴급 중단: 마우스를 화면 **왼쪽 위 모서리**로 확 이동
- 종료: cmd 창에서 `Ctrl+C`
- 최근 10분 이내에 다운로드된 파일만 전송돼요 (옛 파일 재전송 방지)
- 한 번 보낸 파일은 `sent_log.json` 에 기록돼서 다시 안 보내요
- 카톡 채팅방 이름이 바뀌면 `rooms.json` 도 같이 수정하세요

## 문제 해결

| 증상 | 해결 |
|---|---|
| "PC 카카오톡이 실행되어 있지 않습니다" | 카톡 로그인 후 다시 실행 |
| "채팅방을 열지 못했습니다" | rooms.json 의 이름이 카톡 채팅방 이름과 정확히 같은지 확인 |
| 파일이 안 보내짐 | 다운로드 폴더가 기본 위치가 아니면: `set KAKAO_SENDER_WATCH_DIR=D:\내폴더` 후 실행 |
